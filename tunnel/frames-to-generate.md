# The $70 Million Tunnel Heist: script and frames to generate

The narration is already recorded (3:02), so you only need to make the pictures.
Make 30 images, wide format (16:9), with no text in them. I add the captions.

## How to use this

1. Start every prompt with the STYLE block.
2. Add the CHARACTERS block whenever people from the crew appear.
3. Then add the scene line.
4. Save each image with its number (01, 02, 03 ...) and attach them in the chat, a few at a time.

### STYLE (paste at the start of every prompt)

```
Anime illustration, clean dark outlines, flat cel shading with one shadow tone, detailed faces and hands, muted cool colour palette with one warm accent, cinematic lighting, simple slightly blurred background, wide 16:9 frame, no text, no logos, no watermark.
```

### CHARACTERS (add when the crew appears)

```
The leader: man in his early 30s, short black hair, light stubble, calm serious face, dark green work shirt. His crew: three men in matching dark green work shirts and caps. Keep the same faces and clothes in every image.
```
